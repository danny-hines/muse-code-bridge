Mode: built-in `image_gen`, compositing edit. The ChatGPT icon is the base; the prior Codex/Meta icon is a badge reference only. The output is packaged into `chatgpt-muse.png` and `chatgpt-muse.icns` using native macOS icon framing.

## Prompt

Use case: compositing.
Asset type: one square macOS application icon for a ChatGPT + Muse launcher.
Image 1 is the edit target and main identity: the actual ChatGPT application icon. Preserve its dark graphite interwoven ChatGPT knot, exact six-loop silhouette and openings, bevels, lighting, subtle shadow, and white rounded-square tile. Use this ChatGPT mark, not the blue Codex flower or terminal symbol.
Image 2 is a reference ONLY for the small Meta badge: retain that same recognizable blue Meta infinity-loop symbol in a white circular badge with a subtle gray rim and soft shadow, positioned at the lower right. No Meta wordmark, no text.
Add the badge to image 1. Keep it about 27% of the canvas width, centered roughly 76% across and 77% down, overlapping only the lower-right portion of the ChatGPT mark. The main knot should remain clearly recognizable. Match the visual balance of the prior badged launcher, now using ChatGPT as the base.
Output one crisp 1024 by 1024 icon, straight-on, suitable for small Dock sizes. Preserve original tile proportions and padding. Outside the white rounded-square tile, use a plain solid white matte for native icon packaging; absolutely no checkerboard or patterned background. No blue/purple flower, terminal glyph, lettering, scene, or extra logos.
